\subsection{Prioridad Crítica: Integridad Documental}
El riesgo prioritario es el \textbf{R03 (Falsificación documental)}, debido a que los certificados sobre normativas estatales otorgan puntaje en concursos públicos y convocatorias CAS. La certeza jurídica se garantiza combinando el hash criptográfico SHA-256 y la verificación pública instantánea vía código QR.
