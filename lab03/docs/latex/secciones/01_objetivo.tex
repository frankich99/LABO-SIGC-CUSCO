\section{Objetivo}

Identificar y documentar los requerimientos funcionales del proyecto SIGC-CUSCO mediante historias de usuario y construir el Product Backlog inicial.

\subsection{Resultados de aprendizaje}
\begin{itemize}[nosep]
    \item Comprende la elicitación de requerimientos en un proyecto de software.
    \item Redacta historias de usuario con el formato estándar.
    \item Organiza y prioriza un Product Backlog.
\end{itemize}

\subsection{Fundamento teórico}
\begin{itemize}[nosep]
    \item \textbf{Ingeniería de requerimientos:} proceso para descubrir, documentar y validar lo que necesita el sistema.
    \item \textbf{Historias de usuario:} descripciones cortas de funcionalidades desde la perspectiva del usuario (\textit{Como [rol], quiero [acción], para [beneficio]}).
    \item \textbf{Product Backlog:} lista ordenada por prioridad de todo lo que debe tener el producto.
\end{itemize}
